# Boliganga Merch — tienda web (propuesta)

Tienda de una sola página para @boligangamerch. Verde botella y dorado, como el logo BLGNG.

- `index.html`: la página completa (sin dependencias, solo Google Fonts).
- `img/`: fotos de producto recortadas de las publicaciones de la marca.

## Cómo funciona la compra
1. El cliente elige prenda, talla y cantidad.
2. El carrito suma el total y pide nombre, ciudad y forma de pago.
3. "Enviar pedido por WhatsApp" abre el chat con el 591 77860875 con el pedido ya escrito
   (número de orden, prendas, tallas, total, ciudad, pago).

## Antes de publicar
- **Los precios son referenciales** (inventados para la demo). Se cambian en `PRODUCTS` dentro de `index.html`.
- Revisar tallas disponibles y respuestas de "Respuestas al toque" (envíos, pagos, tiempos).
- Se puede subir tal cual a Netlify, Vercel o GitHub Pages.
